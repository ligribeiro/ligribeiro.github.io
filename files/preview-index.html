o site como case

Este site é um design system com duas peles. Alterne e veja.

alternar pele

Um único conjunto de componentes, duas peles sobre a mesma tinta escura: primary laranja para o trabalho de produto e design, primary violeta para desenvolvimento e automação. Os tokens ao lado são lidos ao vivo do CSS computado: alterne a pele e veja os valores mudarem. É a disciplina que apliquei no design system da Compsis, agora aplicada a mim.
